# SSB Covers Modern Website

This is a static business website built from the information and images in the original ZIP file.

## What's changed

- Replaced the old site completely with a modern responsive design
- Removed all cart, basket, PayFast, and checkout functionality
- Removed the video section
- Added a quote-first contact section using WhatsApp and email links
- Kept the site fully static so it works on GitHub Pages

## Files

- `index.html` - main website page
- `styles.css` - styling
- `script.js` - quote message builder
- `assets/images/` - logo and showcase images

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root` folder.
7. Save.
8. GitHub will publish the site and give you a live URL.

## Edit contact details

Open `index.html` and `script.js` if you want to change:

- phone numbers
- email address
- WhatsApp number
- text content


Note: This version keeps all image files in the root folder for simpler GitHub upload.
